# 开发工具与真机验收

本清单是待执行的验收步骤，不表示已在真机通过。自动化只验证 Node 辅助行为、页面/组件/资源引用、WXML 事件处理函数、REST 边界及 JS 语法。需使用已部署 API、初始化数据库和真实微信账号，在微信开发者工具编译后，至少各测试一台 iOS 和 Android 真机。记录型号、微信版本、基础库版本、接口环境与执行日期。

## 登录与家庭

- [ ] 本地 dev:alice 创建家庭，显示一次性邀请码；dev:bob 用该码加入，能看见同一家庭数据。
- [ ] Owner 重置邀请码，旧码不可用；移除非 owner 成员，成员后续接口失去访问权限。
- [ ] 新微信账号真实 wx.login 后进入创建/加入页；已有成员进入菜谱页。
- [ ] 会话过期后只重登一次，再次 401 清理会话；网络不可用时能看到错误并恢复。

## 菜谱

- [ ] 建立含一张封面、两行定量食材、一行适量食材、做法和 HTTPS 链接的菜谱；分类与默认份数保存正确。
- [ ] 搜索菜名及描述，切换分类；超过 20 道菜时分页和回到底部加载正常，空搜索有空态。
- [ ] 编辑保存后重新打开，所有 ingredients/links 仍在；删除确认取消不删除，确认删除返回列表。
- [ ] 测试 1/50 行食材、0/5 链接边界；重复食材、零数量、超出四位小数、空标题显示错误并保留填写内容。
- [ ] 相册和拍照可选单张图片；上传域名配置有效；超过 5 MiB 和非法图片有可恢复错误。
- [ ] 支持来源解析成功时可以采用标题、采用封面；解析失败仍可编辑并保存原链接。
- [ ] 具有 AppID/path 的链接优先跳转；无配置和跳转失败时复制链接并提示；复制失败有提示。

## 库存与推荐

- [ ] 添加不同单位和保质期的批次，余量使用当前 base_quantity，按食材/兼容单位汇总。
- [ ] 临期、过期、已用完分别展示；过期批次不计入可用总量与匹配。
- [ ] 编辑/清空日期和备注；增加、消耗、设定余量后查看流水；数量不足/单位不兼容保留表单并报错。
- [ ] 消耗整批余量后显示已用完；推荐默认两道，1–10 可调整，每道展示匹配及缺料解释。

## 日历与采购

- [ ] 日期选择器切换日期，早餐/午餐/晚餐分别显示安排。
- [ ] 搜索菜谱、勾选多个菜谱、分别设置份数，搜索翻页后已选项保留；确认只发一次 batch 请求。
- [ ] 修改单条份数、删除条目后对应日期餐次正确刷新。
- [ ] 采购默认今天/明天全部餐次；添加不连续日期，按日期分别勾选餐次，未选餐次不生成需求。
- [ ] 清单生成时扣除可用库存；历史清单可打开，勾选可撤销，完成清单后可重新打开。
- [ ] 勾选和完成均不自动入库；实际入库必须填数量/单位，可填日期。
- [ ] 同一 item 在两个设备同时入库，只有一次库存变动；第二次 409 提示已入库并刷新。

## 待办与消息

- [ ] 建立有负责人和截止时间的父任务及一级子任务，编辑及删除有效；删除父任务确认说明级联删除。
- [ ] 待完成/已完成、成员筛选保留匹配子任务的父级上下文；无结果有空态。
- [ ] 完成父任务联动子任务；全部子任务完成联动父任务；重开子任务联动重开父任务。
- [ ] 截止前24小时展示即将到期，超时展示已逾期；编辑器显示北京时间。
- [ ] 分别点击待办/库存授权按钮；仅配置库存模板时授权不会记录为任务类型；拒绝和失败不造成未处理异常。
- [ ] 配置偏好并真实授权后，五分钟 cron 能处理到期提醒；库存每天北京时间09:00形成摘要。
- [ ] 无授权时 runner 记录 skipped_no_grant，应用内提示仍正常；模板字段不匹配有日志可查。
- [ ] 日清理 cron 移除过期临时预览，已采用图片仍可展示。
